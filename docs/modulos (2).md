# Módulos del sistema

- **Usuarios:** Administración de cuentas, roles y estados de acceso.
- **Empleados:** Registro y consulta del personal del restaurante.
- **Clientes:** Registro y consulta de clientes.
- **Mesas:** Control de número, capacidad y estado de las mesas.
- **Menu:** Administración de platos, categorías, precios y disponibilidad.
- **Reservas:** Registro de reservas, cliente, mesa, fecha, hora y cantidad de personas.
- **Pedidos:** Registro de pedidos asociados a una mesa y a un empleado.
- **Facturacion:** Emisión de facturas a partir de pedidos y registro de pagos.
- **Inventario:** Control de existencias y niveles mínimos de productos.
- **Reportes:** Consultas de resumen para apoyar la administración.
