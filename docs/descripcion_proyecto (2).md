# Descripción del proyecto

## Nombre
Sistema de Gestión del Restaurante El Conuco.

## Propósito
Centralizar la información de clientes, empleados, mesas, menú, reservas, pedidos, facturación, pagos e inventario.

## Usuarios identificados en el análisis
- Administrador: administra usuarios, empleados, menú, inventario y reportes.
- Recepcionista: registra clientes y gestiona reservas y mesas.
- Mesero: consulta mesas y registra pedidos.
- Cajero: consulta pedidos, genera facturas y registra pagos.

## Módulos identificados
Login, usuarios, empleados, clientes, mesas, menú, reservas, pedidos, facturación, inventario y reportes.

## Alcance
Esta entrega constituye una base inicial de código y organización. No representa todavía un sistema comercial terminado ni integra servicios fiscales, bancarios o nómina.
