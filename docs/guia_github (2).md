# Guía para publicar en GitHub

1. Crear un repositorio nuevo en GitHub.
2. Abrir esta carpeta en Visual Studio Code.
3. Abrir Terminal > New Terminal.
4. Ejecutar `git init`.
5. Ejecutar `git add .`.
6. Ejecutar `git commit -m "Proyecto base El Conuco"`.
7. Ejecutar `git branch -M main`.
8. Copiar la URL HTTPS del repositorio y ejecutar `git remote add origin URL`.
9. Ejecutar `git push -u origin main`.
10. Abrir el repositorio en GitHub y tomar la captura donde se vea el nombre y las carpetas.
